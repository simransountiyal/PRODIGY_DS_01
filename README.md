# PRODIGY_DS_01

## Prodigy InfoTech Data Science Internship - Task 1

### Task Description

Create a bar chart or histogram to visualize the distribution of a categorical or continuous variable.

### Objective

The objective of this task is to analyze population data and create a bar chart to visualize the population distribution across countries.

### Dataset

The dataset used in this task is the World Bank Total Population dataset provided by Prodigy InfoTech.

### Technologies Used

- Python
- Pandas
- Matplotlib
- Google Colab
- Jupyter Notebook

### Data Analysis

The dataset was loaded and analyzed using Python and Pandas. Population data for 2022 was selected, missing values were removed, and countries were sorted based on their population. The top 10 countries were then selected for visualization.

### Visualization

A bar chart was created using Matplotlib to compare the population of the top 10 most populous countries in 2022.
